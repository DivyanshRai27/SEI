# Super Engineering India website

This is a framework-free static website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — Home
- `about.html` — About
- `products.html` — Products
- `contact.html` — Contact and email enquiry form
- `styles.css` — All website styling
- `script.js` — Mobile navigation, current year, and enquiry email behavior
- `public/` — Logo and product images

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will provide the public website address after the first deployment finishes.

## Preview locally

Open `index.html` directly in a browser, or serve this folder with any basic static web server.
